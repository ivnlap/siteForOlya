# Инструменты проверки

Три скрипта, которыми сайт проверялся при сборке. Зависимостей нет: python3 из системы
и Google Chrome из `/Applications`. В продакшен не входят — это оснастка.

```bash
python3 tools/audit.py .                      # статическая ревизия, 26 проверок
tools/shot.sh . /tmp/shot.png 1440 900        # скриншот в файл
tools/measure.sh . 1440 900                   # JSON с координатами блоков и переполнением
```

- **`audit.py`** — запреты брифа и доступность: чистые `#FFF`/`#000` (комментарии не
  считаются), единственность кнопки, отсутствие подписи у кнопки, текст подвала, H1
  дословно из брифа, `<title>`/`og:title`, `alt` и `width`/`height` у всех картинок,
  подключение маскота с png-фолбэком, `prefers-reduced-motion`, ловушка `minmax(0,1fr)`,
  копирайт страницы в словах, вес первого экрана, контраст пяти пар токенов.
  Ненулевой код возврата, если есть провалы.

- **`shot.sh <корень> <выход.png> <ширина> <высота>`** — скриншот в headless Chrome.
  Копирует сайт во временную папку: Chrome отдаёт закешированный CSS по одному и тому же
  `file://`. Для ширин меньше 500px рендерит во фрейме — headless Chrome не умеет вьюпорт
  уже 500px.

- **`measure.sh <корень> <ширина> <высота>`** — печатает JSON: горизонтальное
  переполнение, высота прокрутки, координаты `.hero`, `.mascot`, `.reel-wrap`, `.micro`,
  размер шрифта H1, число кнопок. Запускается с `--force-prefers-reduced-motion`, иначе
  замер попадает в середину анимации появления и врёт на 24px.
  Внимание: Chrome клампит окно до 500px по ширине, поэтому для 360–390px верить надо
  скриншотам из `shot.sh`, а не этим числам.
