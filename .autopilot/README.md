# Как читать эту папку

- `dashboard.html` — открывается сам в начале сборки; можно и двойным кликом.
  Этапы, прогресс, время, что осталось. Обновляется по ходу сборки.
- `kids-animation-studio-site/2026-08-09-brief.md` — твоя изначальная задача, слово в слово. Не редактируется.
- `kids-animation-studio-site/manifest.md` — список требований и что с каждым стало.
- `kids-animation-studio-site/spec.md` — спецификация: три композиции, контент, адаптив, ассеты.
- `kids-animation-studio-site/tickets/` — таски, на которые разбита сборка.
- `kids-animation-studio-site/interfaces.md` — общий контракт, по которому собраны все три варианта.

Если сборка прервалась — скажи агенту «продолжи автопилот», он поднимет состояние отсюда.
